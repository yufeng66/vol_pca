## Project Setup

Cheap-VaR research on implied volatility surfaces: greeks-based VaR vs full revaluation, with PCA as the current (not only) model of surface dynamics. Python project managed with `uv` (Python 3.14, pinned in `.python-version`); the setup mirrors the `~/vix_refactor` project minus its PyTorch/trading dependencies.

Commands:
- `uv sync` — create/update `.venv` from `pyproject.toml`. Default groups: `dev` (pytest) and `gpu` (torch 2.12.0 pinned, resolved as +cu130 from the PyTorch index on Linux/Windows — the exact build `~/vix_refactor` verified on this machine). `uv sync --no-default-groups --group dev` gives a torch-free env; everything except `vol_pca/rainbow_torch.py` (and its tests, which importorskip) runs without torch.
- `uv run python <script>` — run a script inside the venv.
- `uv run pytest` — run tests (configured for `tests/`, with repo root on `pythonpath` so in-tree packages import without installing).
- `uv run pytest tests/test_foo.py::test_bar` — run a single test.
- `uv run jupyter notebook` — notebooks.
- `uv add <pkg>` — add a dependency.

Main deps: pandas, scikit-learn, scipy, matplotlib, notebook; torch (gpu group, default-installed) used only by `rainbow_torch.py`.

Run the full pipeline: `uv run python scripts/run_analysis.py` (~10s; writes `data/daily_results.csv`, `data/attribution_daily.csv` and `data/factor_model.npz`, all gitignored). ## Project Goal & Status

**The goal is cheap VaR, not PCA** (user, 2026-08-03): compute VaR from a handful of (bumped) revaluations projected across thousands of scenarios instead of fully revaluing every scenario — the real book's exotics are simulation-priced and every valuation is costly. Compact surface representations (PCA is one) are benchmarked on the same test book, scenario engine and rolling backtest.

**History lives in `CHANGELOG.md`** — the research log of every idea tried, newest first; each entry = one plain-language bullet (question → method → conclusion) + `Record:` bullets (functions, numbers, caches, pitfalls). Add an entry there for every substantive experiment — especially negatives — and keep this file operational (current defaults, binding rules, module APIs).

Two test vehicles:
- **Vanilla thread (complete)**: daily-sold $1M 1Y SPX 100/110 call spread (~250-spread steady state). Attribution, sticky-strike factor model, historical VaR (hedged VaR99 gap +0.9% at k=10, ~15 valuations/position vs 3,138 scenarios), rolling backtest over 2,889 books (best small config k=4+cube, hedged mean |gap| 5.6%; k=10+cube 4.7%), the formula-free 32-reval bump path, and the crisis-tail owners: the strike-histogram **gate** (swap when it exceeds the headline by >15%; worst −61%→−15%) plus **dual-screened partial reval** (~5% of the reval budget → +0.0% on the hardest books). Alternative tried and beaten: key-rate level/skew (7.4% vs 5.6%).
- **Rainbow thread (current)**: dataset = SPX/SX5E/HSI triple (1,969 joint dates); daily-sold 1Y 100/112 ranked-basket call spread priced by implied marginals + Gaussian copula. Batched GPU engines (quadrature, CRN Sobol, device marginal factory) and the full-history book attribution are done (6.5 min, residual 0.6% of P&L std, delta-hedged −$11.2M). The cheap-VaR benchmark is measured on a **five-date gamma-regime panel** (2026-08-06, `rainbow_var.ipynb`; ~1 GPU min/as-of — 57s full sweep + 2s greeks — so hand-picked days, not the ~33h rolling history): 2020-03-16 (COVID peak — displaced far-OTM book, LONG SPX gamma), 2021-09-20 (mixed), 2022-03-16 (bear book, short gamma, 1'Γ1 −$640M), 2024-10-08 (rally book), 2026-07-31 (current book, deep ITM). Verdict: the 102-pricing bump projection prices unhedged VaR99 within ~3% (COVID as-of −10%), but its hedged gap is regime-dependent — −2.8% on the short-gamma book vs −18…−49% elsewhere; more factors don't fix it (k=18 ≈ k=12; joint k=4 ≈ per-index k=12 everywhere — 4 joint factors stay the budget config) because the misses are spot-Taylor radius (|dS|≳5%) + linear-vega convexity on the same few crisis scenarios. **Dual-screened partial reval transfers from the vanilla thread and closes it**: worst-100 by each projection ∪ all |dS|>4% (~10% of scenarios) → hedged AND unhedged VaR99 exact (0.0%) on all five books; m=250 (~20–25%) pins VaR95 within ~1%. Budget ladder per as-of: 2s projection → 8s hybrid (VaR99 exact) → 57s full. Open hooks: curve-shock seam (fwd ~4% of daily P&L std, excluded from both engines), vega-weighted loadings, packaging the screen as a driver.

Binding decisions and rules (user):
- **Sticky-strike headline** (2026-08-01): vega-weighted PCA on sticky-strike pillar changes, target = fixed-strike vol P&L ex roll (`vol − vol_roll`; +$15.5M total, daily std $70k), paired with the plain BS delta.
- **Presentation rule**: never headline the `vol_surface`/`pl_vega_full` total — it and the smile slide are large offsetting coordinate artifacts of the moneyness split; quote the fixed-strike vol P&L instead.
- **Formula-free** (2026-08-01): assume greeks exist only via bumped revaluations (1σ-sized, ≤5 vol factors affordable); closed-form greeks are test oracles only. Extended to the rainbow thread (user, 2026-08-06): **sticky-strike bumps are the main greeks path there too** — the autograd delta is sticky-moneyness by construction and a torch-only luxury the real book won't have; it stays as the SM test oracle and the SM attribution driver's `eq_delta` reporting split, never the hedge delta. The SS-hedges-better verdict is now **measured on this book** (same day, `rainbow_attribution_ss` full history): SS delta hedge cuts hedged-P&L std 43% (\$167k→\$94k), halves the worst day, and removes the SM hedge's residual market beta (|corr ret_spx| 0.52→0.14); the 1%-bump gamma+cross terms explain most of the rest (std \$67k, skew −8.4→−1.0).
- **No single-date conclusions** — run the rolling history; three single-date reads reversed there (cube term, vanna cross, key-rate VaR).
- Engine roles & budgets: numpy engines canonical, torch mirrors them in one module; quadrature = engine of record (24×24 = 1,152 nodes ≈ $100/contract), Sobol = production path. **Standing default: 512 Sobol paths** (user 2026-08-06) for book-level pricing and VaR work (≤0.45bp of book notional across the calibration dates); the committed attribution history/cache was built at 2,048 paths (its $100/contract per-option target).

## Architecture (`vol_pca/` package)

The load-bearing design choice: all pricing looks vols up on a fixed per-date **pillar grid** (8 TTM pillars × the 13 quoted moneyness columns, `surface.py`) with **bicubic-spline** interpolation (cubic per axis, not-a-knot ends; `grid_lookup(..., interp="linear")` keeps the old bilinear lookup). Spline interpolation with fixed knots is still *linear in the pillar values*, so every queried vol is an exact linear combination of pillar vols — and scattering each option's vega onto the pillars via those weights keeps the exact identity `pl_vega_lin == bucket_vega · Δσ` (asserted in tests to 1e-9). Caveat: the dense cardinal weights give bucketed vega oscillatory side-lobes (gross |bucket vega| ≈ +34% vs bilinear at unchanged net) — a factor-model input, not a per-pillar hedging report. The identity holds for sticky-moneyness Δσ; the headline sticky-strike Δσ samples between pillars, so its all-factor estimate carries a small extra reconstruction error (all-factor R² 0.985 vs the target).

- `data.py` — loads/cleans the CSV (EOD filter, dup drop, corrupted-upper-wing repair) into `SurfaceData`: per-date pillar grids plus log-linear discount/forward curves.
- `pricing.py` — Black-76 on the forward; spot greeks assume fixed F/S. Returns (price, delta, gamma, vega, vanna) with `greeks=True`.
- `book.py` — daily simulation and sequential attribution against the previous close. Delta is the **smile delta** (surface is moneyness-quoted, so a fixed strike slides along the smile as spot moves) — this sequential view stays sticky-moneyness; the headline factor framework instead pairs sticky-strike factors with the plain BS delta. Vanna is explicit (SPX spot-vol anticorrelation makes it a large systematic drag, −$32M over the sample).
- `attribution.py` — independent (non-waterfall) BS-input attribution: each component is a single-input revaluation from the same previous-close base (equity split delta/gamma/higher, own implied-vol change, r, implied q, time, exact vanna cross). Time splits by the BS PDE into `time_funding` vs pure gamma theta (delta-hedged view = `pl − eq_delta − time_funding`). Vol splits exactly (telescoping full revals) into `vol_surface` (≡ `pl_vega_full`) + `vol_roll` (term roll; `vol_carry_ex` = its ex-ante version, corr 0.98) + `vol_slide` (spot-driven smile slide); the headline PCA target is `vol − vol_roll`. Daily totals match `simulate_book` exactly (tested); residual std ~0.8% of P&L std. Note: q backed out of forward-vs-spot spikes on some stress dates (e.g. 2018-02-06) is a data-snap inconsistency the `div` component absorbs and flags. Notebooks: `attribution.ipynb`, `pca_factors.ipynb`.
- `factors.py` — PCA on daily pillar Δσ with a per-pillar weight transform (`fit_pca(weights="cov"|"corr"|custom)`). **Headline model**: vega-weighted (`w_p` = book's average |bucket vega|) PCA on sticky-strike changes from `sticky_strike_dsigma(sd)` (new surface sampled at m·S₀/S₁ through the pricing interpolant; `interp="cubic"` default, `"linear"`/`"pchip"` variants; the 50/150 edge columns clamp). k=3 R² by weighting: vega 0.811, corr 0.646, cov 0.474 (vega k=10: 0.934; ceiling 0.985); sticky-strike PC1 spot-|corr| 0.34 vs 0.86 sticky-moneyness → pairs with the plain BS delta. Exposures `E_k = (bucket_vega/w)·L_k`, scores `f_k = L_k·((Δσ−μ)∘w)`, estimate `= bucket_vega·μ + Σ E_k f_k`. `include_roll=True` folds term roll in (pillar tracks a fixed strike+expiry, day-t lookup at τ−dt; complete vs attribution `vol`, corr 0.994; roll lands in the factor mean ≈ −$5.3k/day; shortest pillar clamps at the 0.08 TTM edge); k=3 suffices for exposure reporting (R² 0.82) but stress days need k≈10 (big-move R² 0.66→0.83, p99 error $115k→$57k). `model.score_std` = fit-sample score stds — the natural 1σ bump sizes. `bumped_factor_exposures(price_fn, model, k, eps)` measures the same exposures by central differences along each factor's unit-score move `L_k/w` (2k+1 revals + free PC1 curvature; matches analytic to 6e-6 worst rolling date); the `½c·f₁²` add-on helps the daily vol estimate (k=10 R² 0.937→0.946) but not crisis books. Notebooks: `pca_factors.ipynb`, `sticky_strike.ipynb` (the cubic-flip comparison), `roll_in_pca.ipynb`.
- `var.py` — historical 1-day VaR, two engines over one scenario set: each historical day pair is a joint scenario (spot ratio, fixed-moneyness pillar Δgrid, Δr/Δq at each leg's TTM, calendar-gap dt) applied to a fixed as-of book (`build_book`; closed-form greeks live there as test oracles). `full_reval_pnl`: shocked grid sampled at each leg's new moneyness and dt-decayed lookup TTM with the BS time input frozen — slide and roll-down realize on the as-of surface; scenario P&L is pure market shock (no theta/funding). `greeks_pnl`: one base-date greeks pass (delta/gamma, bucketed vega → factor exposures, bucketed vanna × the k-factor Δσ reconstruction, 1bp rho/div); factor scores from `scenario_dsigma` — each scenario's pillar move **re-anchored on the as-of surface** (reusing fit-sample historical scores understates hedged VaR99 by 12% — don't). Headline results: hedged VaR99 $183k full reval, greeks k=10 +0.9%; rolling hedged mean |gap| 5.6% (k=4+cube) / 4.7% (k=10+cube); crisis as-of dates understate ~60% at any k≤10 = factor truncation from frozen average-book weights (k=104 −14%). Crisis owners: **gate** — report strike-hist VaR when it exceeds the headline by >15% (fires 24/2,889, worst −61%→−15%, bulk unchanged); **dual-screened partial reval** — fully revalue top-100 scenarios of each projection ∪ all |dS|>4% (~5% budget; the dual rank matters — Taylor terms overshoot big-dS scenarios). `strike_histogram_weights` + `rolling_var_adaptive` = the statics-only adaptive weights (Gaussian kernel at every leg's strike, notional mass, floor 0.05 — full histogram, low floor); worse in the bulk (6.6% vs 4.7%) → run as a parallel drift alarm; divergence = refresh the vega weights. **Formula-free main path**: `book_reval_fn` = the single `price(spot, dsigma, dr, dq)` entry (vol lookups frozen at base moneyness — re-mapping under spot bumps double-counts the slide the sticky-strike scores carry and distorts crosses up to 30×); `bump_greeks` = 10+2k+4·k_cross = 32 revaluations at defaults (spot stencil ±1/2%, mean-move reval, five ±1σ factor pairs → exposures + free diagonal curvatures, 4-corner PC1-3 spot×factor crosses — essential, ±5bp parallel rate/div); `bump_pnl` projects scenarios (rate/div must hit a |units|·TTM-weighted mean of per-leg moves, never a plain mean — implied-q 1/T snap noise); PC1² quad off by default for VaR. Rolling drivers `rolling_var_backtest`/`rolling_var_adaptive`/`rolling_var_bump` cache via `scripts/run_var_rolling.py`. Notebook: `historical_var.ipynb`.
- `key_rate.py` — the first alternative surface representation (user spec 2026-08-03): fit-free key-rate level/skew, two shapes per quarterly knot (3/6/9/12M tent weights in TTM so level sens sum exactly to net vega; TTM<3M clamps to 3M; skew = tilt (m−100)/5 vol pts, deliberately unclamped wings), realized moves = simple interpolant reads (sticky-strike ATM change per knot, (Δσ₁₁₀−Δσ₉₀)/4). `key_rate_sens` evaluates shapes per leg on u·vega / u·vanna (never a pillar-grid representation of the shapes; free of vega side-lobes); `bumped_key_rate_sens` = the same 8 numbers in 16 revaluations; `key_rate_pnl`/`rolling_var_keyrate` mirror the greeks path (cache `data/var_rolling_keyrate.csv`). **Verdict**: loses to fitted factors (attribution R² 0.705 vs 0.811; rolling hedged 7.4% vs 5.6%; same crisis tail — the displaced-book failure is realized-move curvature, basis-independent); the book is structurally a *skew* book. Measured round-two headroom: butterfly reads lift the ceiling to 0.790. Notebook: `key_rate.ipynb`.
- `rainbow.py` — multi-underlying exotic valuation (user spec 2026-08-05), template for the real book's simulation-priced rainbows: 1Y call spread (100/112%) on the ranked basket `B = 0.5·best(P_spx, P_sx5e) + 0.3·worst + 0.2·P_hsi`, $1M notional sold, joint-quote dates only. Pipeline: `implied_marginal` — Breeden–Litzenberger through the bicubic smile on a log-spaced performance grid (CDF = 1 + C′; quantile function for sampling; mean matches the forward <1bp, tested). Wings beyond 50–150 continue at the edge slope, exponentially tapered (scale 50 mon pts, floor 0.25× edge vol): flat clamps teleport a ~2–3% Dirac of mass (−30bp mean bias), unbounded slopes violate Lee's bound on rising call wings; ~1e-4 residual negative-density mass remains. → Gaussian copula `sample_performances` (`method="sobol"` = scrambled QMC, powers of two) with one constant `historical_corr` on **5-day overlapping** log returns (daily returns understate async-close co-movement). → USD (SPX-curve) discounting, no FX/quanto per spec. `price_rainbow` = the MC wrapper (seasoning via `perf_to_date`: total performance = g·X, strikes in sale-date units); `price_rainbow_quad` = deterministic (HSI conditioned out via normal-score survival integral, Gauss–Hermite × Gauss–Legendre split at the rank kink; replaces MC for ≤3 European underlyings, doesn't generalize to path-dependents); `marginal_call_spread` = 1-D single-index quadrature; `bs_implied_vol` = smile round-trip checker. Control-variate experiment (2026-08-06, measured negative — CV doesn't compose with scrambled Sobol): `geo_basket`/`price_geo_quad`/`price_rainbow(cv="geo")` kept CPU-only with the verdict in docstrings; its flat-lognormal Black test doubles as an end-to-end machinery check. Notebook: `rainbow_option.ipynb`.
- `rainbow_torch.py` — **the single torch module** (nothing else imports torch; numpy engines stay canonical, tests pin parity): batched GPU engines + the rainbow attribution driver. `QuadBatch.from_problems` stacks B problems into device tensors (`scores=False` skips the psi tables a Sobol-only batch doesn't need); `price_quad_batch` mirrors `price_rainbow_quad` line-for-line — fp32 only for the `(B, nodes, grid)` survival/trapezoid stage (consumer fp64 runs at 1/64 rate; `survival_dtype=torch.float64` for full parity), fp64 for node placement/interps/accumulation, chunked under `max_bytes` (2GiB), survival stage gradient-checkpointed per chunk (else backward OOMs the 8GB card at book scale); autograd on `QuadBatch.g` = exact per-vintage spot deltas in one backward. `sobol_normals(n_slots, n_paths)` = one scrambled scipy-Sobol point set per book slot, generated once on CPU, device-resident; a vintage keeps its slot's points across every day and component reval (common random numbers — differences cancel sampling noise) while slot scrambles are independent (book errors √-average, verified). `price_sobol_batch(batch, normals, slots)` = the production sampler (replays the numpy sampler to ~1e-11; requires power-of-two paths). `MarginalFactory` builds x/cdf/psi tables on device: pillar grids + curve nodes upload once (~10MB); fixed knots ⇒ the scipy not-a-knot solves bake into constant cardinal-coefficient tensors (searchsorted + gather + Horner) with an exact `np.gradient` replica; VaR seams, parity-tested: `dgrid` additive pillar-vol shocks, two-tau roll convention (`tau` lookup vs `tau_price`), `di_curve` decoupling. Known quirk (CPU-identical): BL mean-vs-forward gap ~43bp on COVID-crash surfaces (calm <1bp). Throughput (RTX 4070 Laptop 8GB, WSL2): quad 4.5 ms/price at 48×48 on the 250-book (74× the numpy loop); Sobol 17–22µs/price at 2,048 paths; factory 24 ms/date for 750 tables (~11× one core, ≈ parity vs the 20-core pool — its value is latency + the on-device build→price loop; CPU oracle build 0.4s/book). Operating points: quad 24×24 = 1,152 nodes ≈ Sobol 2,048 paths ≈ $100/contract (quad carries an oscillatory ~$150 crash-surface tail more nodes don't fix; single-input differences cancel it); book-level marks need only 256–512 paths for <1bp of book notional. `rainbow_attribution(sds, ...)` = the daily-sold book driver (independent single-input revals off the t−1 close on the CRN engine: eq incl. autograd `eq_delta`, per-index `vol_*` + `vol_cross`, `time` + two-tau `time_roll`, `fwd`, `rate` = free df multiplier, `cross_sv` 4-corner spot×vol, `resid`; expiries settle at intrinsic; `engine="quad"` + `t_slice` for window reruns; ~197 ms/date → 6.5-min history); cache via `scripts/run_rainbow_attribution.py` → `data/rainbow_attribution.csv`; results and validation in `rainbow_attribution_sm.ipynb` (the original study, renamed 2026-08-06 — historical reference only) and the changelog. **Book spot greeks** (user spec 2026-08-06): `prepare_book_greeks`/`book_greeks`/`rainbow_book_greeks` = sold-book delta vector + full gamma/cross-gamma matrix by central 1% bumps (base + 6 singles + 12 pair corners = 19 pricings + 6 shifted table builds, ~0.1s/book); `mode="sticky_strike"` (default) re-derives each bumped index's implied distribution from the moneyness-shifted smile via `MarginalFactory.strike_shift_dgrid` (σ_new(m) = σ_old(m(1+ε)), the vanilla sticky-strike sampling) and scales its g — `"sticky_moneyness"` freezes tables (what the autograd delta measures; the two coincide in a flat world, tested). Greeks are per relative move ($/100%); gamma must come from bumps (pathwise-linear payoff ⇒ autograd Hessian 0 a.e. through the sampler); 512 paths confirmed for the whole matrix (noise ≤0.026bp of book notional per 1% move — CRN differences converge better than the price); on crash surfaces trust the CRN-Sobol FDs over quad FDs (oscillatory node tail). Study + convergence + hedge verdict: `rainbow_greeks.ipynb`. **`rainbow_attribution_ss`** (user spec 2026-08-06) = the sticky-strike re-cut of the attribution: eq = all spots → t with each index's tables re-derived from the realized-ratio-shifted smile, attributed by the 1%-bump matrix (per-index `eq_delta_*`/`eq_gamma_*`, per-pair `eq_xgamma_*_*`, `eq_resid`); vol = day-t surfaces at fixed strikes (grid-t rows sampled at m/u, singles + `vol_resid`); `cross_ev` = 4-corner equity×vol on the totals (eq and vol compose exactly: both applied = plain day-t tables at g1); theta 3-split (`theta_value` = df decay on base pv, zero revals; `theta_delta` = per-vintage SS deltas × per-vintage forward-ratio decay, from the greek singles' pv vectors; `theta_gamma` = rest per spec); pl/time/fwd/rate construct-identical to the SM driver (match to fp at equal paths/seed, tested); ~30 builds + 30 pricings/date at 512 paths ≈ 260ms → 8.5-min history; cache `data/rainbow_attribution_ss.csv`, presented in the canonical `rainbow_attribution.ipynb` (sticky-strike only, analysis-off-cache, 1.8s runtime). **Rainbow VaR** (user spec 2026-08-06): `rainbow_scenarios` → RainbowScenarios (per-index spot ratios, fixed-moneyness Δgrids, dt over joint pairs); `rainbow_var_full` = the nested sweep, chunked scenarios×vintages through `tables()` per-problem (B,8,13) dgrids at (τ−dt, tau_price=τ) and g·u — the scenario dgrid is the RAW fixed-moneyness change (no strike shift: the factory x-grid already reads at new-spot moneyness; the attribution's eq+vol composition identity is the proof), curves frozen (fwd ~4% of daily P&L std stays out of both engines); `rainbow_fit_dsigma`/`rainbow_scenario_dsigma` = roll-in sticky-strike pillar moves over joint pairs / re-anchored on the as-of grid (lookups only, the vanilla re-anchoring rule); `rainbow_bump_greeks` → RainbowBumpGreeks (SS spot block ±1%/±2% → delta/gamma/speed + pair corners → cross-gammas; factor pairs on ±1σ dgrid bumps → exposures + free curvatures; 4-corner spot×factor crosses compose the strike shift ON the factor-shocked grid via `strike_shift_dgrid(extra=...)`; one factor-mean reval); `rainbow_bump_pnl` = the zero-valuation projection (cube on, quad off — quad widens VaR gaps here too). Identity tests (`tests/test_rainbow_var.py`): pure-spot scenario ≡ the SS bump combo and exposure+curvature telescoping ≡ full reval, both to fp.

Conventions: vols as decimals internally (quoted % / 100), TTM in ACT/365, moneyness in %-of-spot units (50–150). Days after data gaps of `gap_days > 7` are excluded from PCA fitting and metrics — a no-op on the current 2018+ files (max gap 4 days), retained from the original longer SPX history and harmless.

## Datasets: `SPX_volSurface.csv`, `SX5E_volSurface.csv`, `HSI_volSurface.csv`

Implied-vol surface snapshots for three indices, one file per underlying, identical schema (~33.7k rows each). Coverage 2018-12-27 through 2026-07-31: 1,969/1,970/1,971 dates after cleaning, **1,969 joint dates** where all three quote (rainbow work only evaluates on those), ~17 terms per date out to ~9.5Y, no month-long gaps (max calendar gap 4 days). Each row is one term (expiry) of one day's surface; a day's full surface spans multiple rows sharing the same `AsOfTime`. Quirks handled by the loader: 17 non-EOD rows (SPX), ~200–221 exact-duplicate (date, term) rows per file, 6 repaired far-call-wing rows (SPX). **These files replaced the original `SPX_volSurface 2.csv` (2013-12-30→2026-05-12, ~55k rows) on 2026-08-05** — committed notebook outputs and cached `data/` results for the vanilla-book/VaR studies were computed on that longer history and will shift if the pipeline is rerun on the new SPX file.

Columns:
- Unnamed first column: integer row index.
- `50, 60, 70, 80, 90, 95, 100, 105, 110, 120, 130, 140, 150`: implied vols (in %) at moneyness levels expressed as percent of spot (100 = ATM).
- `AsOfTime`: snapshot timestamp (e.g. `2013-12-30T23:59:59Z`), the natural time-series key.
- `Term`: option expiry date; combined with `AsOfTime` gives time-to-maturity.
- `Forward`, `ImpliedSpot`, `DiscountFactor`: per-term forward, spot, and discount factor.
- `DataSourceId`, `IsEndOfDay`, `UnderlyingIndex`, `VolSurfaceId`, `VolSurfaceTypeId`: metadata.

The stray `* N.csv:Zone.Identifier` files are Windows download artifacts and can be ignored.
