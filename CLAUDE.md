## Project Setup

Cheap-VaR research on SPX implied volatility surfaces: greeks-based VaR vs full revaluation, with PCA as the current (not only) model of surface dynamics. Python project managed with `uv` (Python 3.14, pinned in `.python-version`); the setup mirrors the `~/vix_refactor` project minus its PyTorch/trading dependencies.

Commands:
- `uv sync` — create/update `.venv` from `pyproject.toml` (dev group including pytest installs by default).
- `uv run python <script>` — run a script inside the venv.
- `uv run pytest` — run tests (configured for `tests/`, with repo root on `pythonpath` so in-tree packages import without installing).
- `uv run pytest tests/test_foo.py::test_bar` — run a single test.
- `uv run jupyter notebook` — notebooks.
- `uv add <pkg>` — add a dependency.

Main deps: pandas, scikit-learn, scipy, matplotlib, notebook.

Run the full pipeline: `uv run python scripts/run_analysis.py` (~10s; writes `data/daily_results.csv`, `data/attribution_daily.csv` and `data/factor_model.npz`, all gitignored).

## Project Goal & Status

**The goal is cheap VaR, not PCA** (user, 2026-08-03): find ways to compute VaR via a greeks-based approach — a handful of (bumped) revaluations projected across thousands of scenarios — instead of fully revaluing every scenario, because the real book's exotics are simulation-priced and every valuation is costly. Capturing vol-surface dynamics compactly is the enabling sub-problem; PCA factors are the representation tried so far, **not the only one that will be tried** — candidate alternatives should be benchmarked on the same test book, scenario engine, and rolling backtest. First alternative tested (2026-08-03): fixed key-rate level/skew shapes per quarterly knot (`key_rate.py` + `key_rate.ipynb`) — interpretable, fit-free, 16 revals, but rolling hedged VaR |gap| 7.4% mean vs 5.6% for PCA k=4+cube and the same −67% crisis tail; details in the `key_rate.py` bullet below. Test vehicle: every day sell a $1M-notional 1Y SPX call spread (short 100%, long 110% strike), giving a steady-state book of ~250 spreads; attribute daily P&L, compute the book's exposure to each factor of surface moves, and estimate vol P&L as exposure × daily factor movement (done). The headline framework is **sticky-strike** (user decision 2026-08-01): factors fit to sticky-strike pillar changes, targeting the book's fixed-strike vol P&L ex term-roll carry (attribution `vol − vol_roll`; total +$15.5M, daily std $70k), paired with the plain BS delta. Presentation rule from the user: do **not** quote the total of `vol_surface`/`pl_vega_full` as a headline number — it and the smile slide are large offsetting coordinate artifacts of the moneyness split; quote the fixed-strike vol P&L instead. The central deliverable — greeks-projection VaR benchmarked against full revaluation — is in place (`var.py` + `historical_var.ipynb`): 1-day historical VaR of the last-date book over 3,138 joint scenarios — delta-hedged VaR99 $183k by full reval vs $185k (+0.9%) for the greeks projection at k=10 (~15 valuations per position vs 3,138; k=3 understates the tail by 10%, all-factor matches to 0.1%). A rolling backtest over all 2,889 as-of books tempers the single-date read: median hedged |gap| 3.0% at k=10 (4.3–5.9% at k=3–5), the third-order equity term is worth including (~0.5pp mean hedged improvement at small k for two extra spot bumps — a whole-history reversal of the misleading single-date test), and crisis-peak as-of dates understate by ~60% at any k — diagnosed as factor truncation from the frozen average-book weights, not vega convexity: the displaced book's vega sits in far-wing pillars the fixed weights ignore. The statics-only adaptive weighting built for that (`strike_histogram_weights`, user-requested, no greeks) caps the failure (worst understatement −61% → −22%, zero books beyond −30%) but is worse on average (hedged mean |gap| 6.6% vs 4.7% at k=10+cube, better on only 35% of days) — kept as a parallel drift alarm, not the headline method.

## Architecture (`vol_pca/` package)

The load-bearing design choice: all pricing looks vols up on a fixed per-date **pillar grid** (8 TTM pillars × the 13 quoted moneyness columns, `surface.py`) with **bicubic-spline** interpolation (cubic per axis, not-a-knot ends; `grid_lookup(..., interp="linear")` keeps the old bilinear lookup). Spline interpolation with fixed knots is still *linear in the pillar values*, so every queried vol is an exact linear combination of pillar vols — the weights are dense cardinal-basis products (global, can be negative) instead of bilinear's 4 local ones — and scattering each option's vega onto the pillars via those weights keeps the exact identity `pl_vega_lin == bucket_vega · Δσ` (asserted in tests to 1e-9). Caveat of the dense weights: bucketed vega gets oscillatory side-lobes (gross |bucket vega| ≈ +34% vs bilinear at unchanged net), so it is a factor-model input, not a per-pillar hedging report. The identity holds for sticky-moneyness Δσ (pillar-point differences); the headline sticky-strike Δσ samples between pillars, so its all-factor estimate carries a small extra reconstruction error on top of vega convexity (all-factor R² 0.985 vs the target).

- `data.py` — loads/cleans the CSV (EOD filter, dup drop, corrupted-upper-wing repair) into `SurfaceData`: per-date pillar grids plus log-linear discount/forward curves.
- `pricing.py` — Black-76 on the forward; spot greeks assume fixed F/S. Returns (price, delta, gamma, vega, vanna) with `greeks=True`.
- `book.py` — daily simulation and sequential attribution against the previous close. Delta is the **smile delta** (surface is moneyness-quoted, so a fixed strike slides along the smile as spot moves) — this sequential view stays sticky-moneyness; the headline factor framework instead pairs sticky-strike factors with the plain BS delta. Vanna is explicit because SPX spot-vol anticorrelation makes it a large systematic drag (−$32M over the sample).
- `attribution.py` — independent (non-waterfall) Black-Scholes-input attribution: each component is a single-input revaluation from the same previous-close base (equity split delta/gamma/higher, the option's own implied-vol change, zero rate r, implied dividend yield q, time, exact vanna cross). The time component is split by the BS PDE into `time_funding` (financing premium + carrying the delta hedge) vs pure gamma theta, so a delta-hedged view = `pl − eq_delta − time_funding`. The vol component splits exactly (telescoping full revals) into `vol_surface` (≡ book.py's `pl_vega_full`) + `vol_roll` (term roll; `vol_carry_ex` is its ex-ante version off the previous close — anticipatable carry, corr 0.98) + `vol_slide` (spot-driven smile slide). The headline PCA target is `vol − vol_roll` (fixed-strike vol ex anticipatable carry) = `vol_surface + vol_slide`. Daily totals match `simulate_book` exactly (tested); residual std is ~0.8% of P&L std. Inspected in `attribution.ipynb` (root; executed outputs committed); the factor model and this reconciliation are illustrated in `pca_factors.ipynb`. Note the q backed out of forward-vs-spot spikes on some stress dates (e.g. 2018-02-06) — a data snap inconsistency the `div` component absorbs and flags.
- `factors.py` — PCA on daily pillar Δσ with a per-pillar weight transform (`fit_pca(weights=...)`): `"cov"` (plain), `"corr"` (standardized), or a custom array. The **headline model** is vega-weighted (`w_p` = book's average |bucket vega|) PCA on **sticky-strike** pillar changes from `sticky_strike_dsigma(sd)` (new surface sampled at m·S₀/S₁ with the pricing interpolant, `interp="cubic"` default with `"linear"`/`"pchip"` variants: surface move + smile slide at fixed TTM, roll excluded; the 50/150 edge columns clamp). Target: fixed-strike vol P&L ex roll. k=3 R² by weighting: vega 0.811, corr 0.646, cov 0.474 (vega k=10: 0.934; all-factor ceiling 0.985). Exposures `E_k = (bucket_vega/w)·L_k`, scores `f_k = L_k·((Δσ−μ)∘w)`, estimate `= bucket_vega·μ + Σ E_k f_k`. Sticky-strike factors are far less spot-entangled than sticky-moneyness ones (PC1 |corr| with spot returns 0.34 vs 0.86) and pair with the plain BS delta. `include_roll=True` folds the term roll in too (pillar tracks a fixed option: strike and expiry, day-t lookup at τ−dt), making the basis complete against the full attribution `vol` (all-factor corr 0.994, cumulative within $0.5M with no carry line; loadings identical to ex-roll — roll just moves into the factor mean, ≈ −$5.3k/day; shortest pillar clamps at the 0.08 TTM edge); explored in `roll_in_pca.ipynb`, which also shows k=3 suffices for exposure reporting (R² 0.82) but stress days need k≈10 (big-move R² 0.66 → 0.83, p99 error $115k → $57k). The comparison that motivated the switch is `sticky_strike.ipynb`: with cubic sampling sticky-strike beats moneyness-PCA + slide at every k (k=3 R² 0.81 vs 0.77, ceiling 0.985 vs 0.955 — linearizing the net $70k move beats linearizing the two big offsetting pieces); under the old bilinear sampling the ranking was reversed — kinked bracket-crossing samples read as pillar noise and faked a ~+$9k/day carry drift in the factor mean (linear interpolation overestimates the convex smile between nodes). The factor machinery is illustrated in `pca_factors.ipynb`. `fit_pca` stores each factor's fit-sample score std (`model.score_std`) — the natural 1σ bump sizes for the bump path. `bumped_factor_exposures(price_fn, model, k, eps)` computes the same exposures by bump-and-revalue — central differences of the book value along each factor's unit-score surface move `L_k/w` (2k+1 revaluations), plus the PC1 curvature `d²V/df₁²` free from the same pair — for pricers with no cheap vega (the real book's simulation-priced rainbows); `book_price_fn(book)` in var.py is the test-book closure, and the bump route matches the analytic exposures over the whole rolling history (worst date 6e-6 relative). The `½c·f₁²` quadratic add-on (bumps sized ~3σ of fit scores; curvature is ε-stable, c(±1σ)≈c(±3σ)) improves the daily vol estimate (k=10 R² 0.937→0.946, big-move RMSE −9%) and trims VaR nonlinearity modestly (hedged mean |gap| 4.74→4.65%, days>10% 11.4→9.8%, k=4 5.64→5.39) but does not touch crisis-book understatements — that residual is spot×vol cross + truncation, owned by the gate/screen below.
- `var.py` — historical 1-day VaR, two engines over the same scenario set. Each historical day pair is one joint scenario (spot ratio, fixed-moneyness pillar Δgrid, Δr/Δq at each leg's TTM, calendar-gap dt) applied to a fixed as-of book (`build_book`: close-of-day legs incl. that day's new spread). `full_reval_pnl` samples the shocked grid at each leg's new moneyness and dt-decayed lookup TTM with the BS time input frozen — slide and roll-down realize on the as-of surface (the roll-in basis as a scenario engine); scenario P&L is pure market shock (attribution's equity+vol+rate+div+vanna, no theta/funding). `greeks_pnl` projects scenarios from one base-date greeks pass (delta/gamma, bucketed vega → factor exposures, bucketed vanna paired with the k-factor Δσ reconstruction, 1bp rho/div bumps); factor scores come from `scenario_dsigma` — each scenario's pillar move re-anchored on the as-of surface, grid lookups only. Reusing the fitting sample's historical scores instead drops R² 0.95→0.81 and understates hedged VaR99 by 12%, so don't. As-of 2026-05-12 (net long vega ≈ $160k/vol pt from strike drift, net short delta −$48M/100%): hedged VaR99 $183k full reval; greeks k=3 −9.6%, k=5 +3.8%, k=10 +0.9%, all-factor −0.0% (bulk R² ~0.95 at every k — k buys the tail: worst-1% mean |err| $58k→$23k, tail overlap 25→28 of 31). Ablation: drop gamma +31% (long gamma cushions), vanna/rate/div <2% at the quantile; worst hedged scenarios are vol-crush days (2020-03-19 −$1.5M, 2018-02-07). Raw VaR99 $1.24M is delta-dominated (+7–10% rebound days). `rolling_var_backtest` (fork-pool over as-of dates, ~7 min on 22 cores; `scripts/run_var_rolling.py` caches gitignored `data/var_rolling.csv`) reruns both VaRs for every as-of date ≥ 252 with k∈{3,4,5,10} ± the third-order equity term `book_speed`/6·dS³ (5-point spot stencil): hedged mean |gap| 7.1/6.3/6.1/5.0% plain → 6.7/5.6/5.7/4.7% with cube (helps ~60% of days at k=3–4; raw neutral-to-worse at k≤5), best small config k=4+cube; rolling books span net vega −$376k..+$208k (short on 43% of days); worst as-of 2020-03-16 understates 56–66% at every k ≤ 10 with these weights (k=104 −14%: truncation, not convexity — the displaced book's vega sits in far-wing pillars the average-book weights ignore; refitting with own-book |bucket vega| gets k=10 to −19%). `strike_histogram_weights` + `rolling_var_adaptive` (per-date PCA refit, `s{k}*` columns, cache `data/var_rolling_strike.csv`, ~35 min) test the statics-only version: Gaussian kernel (5 mon-pts) at every leg's strike, notional mass, floor 0.05 of peak — lessons: full histogram not per-bucket average strike (averages drift to vol-dead ITM legs), floor low (0.2+ re-admits noisy short-dated wings; floor 1 = cov PCA). Rolling result: caps displaced-book failures (2020-03-16 −61% → −15% at k=10+cube; zero understatements beyond −30% vs 4) but worse in the bulk (mean |gap| 6.56% vs 4.74%, better on 35% of days; k=4 collapses to 20%) → parallel drift alarm, divergence = refresh the vega weights. Notebook: `historical_var.ipynb`. Method-review findings (2026-08-01, scratchpad passes, not yet in the notebook): rolling all-factor (k=104) shows the bulk greeks-VaR gap is genuine nonlinearity (mean |gap| 4.74% → only 4.00% at k=104) while the crisis tail is truncation (−61% → −14%), so no weighting/factor-count change beats ~4% bulk — relative floors on the vega weights are *worse* (worst −68/−75%; exposure noise via `E=vega/w` in barely-weighted wings — the strike-histogram works via kernel mass at the book's strikes, not its floor) and stress-day-only fitting is a no-op. Two fixes that work: **gate** the headline VaR with the strike-hist number (swap when it exceeds by >15%: fires 24/2,889 days, bulk unchanged at mean 4.62%, worst −61% → −15%, clean separation — bulk divergence p95 +7% vs ≥+25% on every big failure); **dual-screened partial reval** — rank scenarios by both projections, fully revalue the top-100 of each ∪ all |dS|>4% (~120–160 revals ≈ 5% of the budget) → +0.0% on the seven hardest books, ≤0.38% mean (the dual rank matters: cube/gamma Taylor terms overshoot on ±10% dS scenarios and rank true tail scenarios as wins; raw-VaR ranking is near-perfect, p99 coverage 47 scenarios). **The main projection path is formula-free** (user decision 2026-08-01: assume greeks exist only via bumped revaluations, 1σ-sized, ≤5 vol factors; closed-form greeks stay in `build_book` solely for tests/validation): `book_reval_fn` is the single `price(spot, dsigma, dr, dq)` entry (vol lookups frozen at base moneyness — re-mapping under spot bumps double-counts the slide the sticky-strike scores carry and distorts the crosses up to 30×), `bump_greeks` measures everything in 10+2k+4·k_cross = 32 revaluations at the defaults (spot stencil ±1/2%, mean-move reval, five ±1σ factor pairs → exposures + free diagonal curvatures, 4-corner PC1-3 spot×factor crosses, ±5bp parallel rate/div), and `bump_pnl` projects scenarios (rate/div hit a |units|·TTM-weighted mean of per-leg moves — a plain mean lets the 1/T-amplified implied-q snap noise of near-zero-sensitivity short legs poison the term, p99 $90k/max $1.3M before the fix). `rolling_var_bump` + a third `run_var_rolling.py` pass cache `data/var_rolling_bump.csv`. Whole-history: bump k=5+cube hedged mean |gap| 6.4% vs formula path 5.7% at the same k (median 5.3 vs 4.3; identical −65% crisis tail = k=5 truncation, owned by the gate/screen); spot×factor crosses are essential (dropping them: 166+ books < −30% — the single-date "<2%" vanna ablation was a one-date mirage), PC4-5 crosses add nothing, and the PC1² quad is off by default for VaR (widens k=5 gaps ~0.2-0.5pp) while lifting the daily vol-estimate R² 0.860→0.875.

- `key_rate.py` — **the first alternative surface representation** (user-specified 2026-08-03): desk-style key-rate sensitivities instead of fitted factors, no fitting anywhere. Two shapes per quarterly knot (3/6/9/12M, tent weights in TTM so the four level sens sum exactly to net vega; TTM < 3M clamps onto the 3M knot): **level** = parallel bump at the spread's own maturity, **skew** = tilt (m−100)/5 vol pts (+1 @ 105, −1 @ 95, deliberately unclamped into the wings per user). Realized moves are deliberately simple single-point reads through the pricing interpolant (only the 9M knot interpolates): sticky-strike ATM change at each knot, and (Δσ₁₁₀ − Δσ₉₀)/4. Sens grouping is per-leg shape *evaluation* (`key_rate_sens` on u·vega, and on u·vanna for the VaR cross term) — never a pillar-grid representation of the shapes (a 9M tent isn't representable on the TTM pillars, which have no 0.75 node) and free of the bucketed-vega side-lobes; `bumped_key_rate_sens` measures the same 8 numbers in 16 revaluations (matches closed form to 6e-4 at the literal 1-pt bump). `key_rate_pnl` mirrors `greeks_pnl` with the vol+vanna terms swapped; `rolling_var_keyrate` is a greeks-only rolling pass (4th pass in `run_var_rolling.py`, cache `data/var_rolling_keyrate.csv`, joins the cached full reval). **Verdict (`key_rate.ipynb`)**: interpretable and lean — the call-spread book is structurally a *skew* book (last date ≈ +$0.9M per unit tilt vs $160k/pt net level vega, concentrated 6–9M) — but at this simplicity it loses to fitted factors: attribution R² 0.705 vs PCA k=3's 0.811 (k=8 0.927), bulk error tails ≈ k=3 but max 2× worse ($1.4M on 2020-03-16, whose smile move is violently non-monotonic in moneyness — curvature outside the level+tilt span, so the 3-point reads scored a −$1.26M estimate against a +$140k truth); rolling hedged VaR99 mean |gap| 7.4% +cube / 8.3 plain vs 5.6/4.7% for PCA k=4c/k=10c, better on only ~⅓ of days, >10% gap on 29% of days, and the **same crisis tail** (2020-03-16 −67% vs −61%: the displaced-book failure is realized-move curvature, basis-independent — still owned by the gate/screen); raw VaR gap 3.3% vs 0.9% (k=10c). The single-date VaR read (−0.7%, beating greeks k≤5 as-of 2026-05-12) was a mirage — the third single-date reversal in this project. Measured headroom for round two: butterfly reads (90+110−2·ATM)/2 lift the in-sample ceiling 0.705→0.790, a wider 80–120 skew read alone reaches 0.750, a short-end read adds nothing — all just extra rows of the same sens/score machinery.

Conventions: vols as decimals internally (quoted % / 100), TTM in ACT/365, moneyness in %-of-spot units (50–150). Days after the two month-long data gaps (Oct 2014, Oct–Nov 2015; `gap_days > 7`) are excluded from PCA fitting and metrics.

## Dataset: `SPX_volSurface 2.csv`

SPX implied volatility surface snapshots, ~55k rows covering 3,141 trading days from 2013-12-30 through 2026-05-12 (after cleaning). Each row is one term (expiry) of one day's surface; a day's full surface spans multiple rows sharing the same `AsOfTime`. Known quirks handled by the loader: 17 non-EOD rows, 1,462 exact-duplicate (date, term) rows, a corrupted far-call wing on a few Feb 2016 short-term rows (140-col halved, 150-col zeroed), and the two month-long gaps noted above.

Columns:
- Unnamed first column: integer row index.
- `50, 60, 70, 80, 90, 95, 100, 105, 110, 120, 130, 140, 150`: implied vols (in %) at moneyness levels expressed as percent of spot (100 = ATM).
- `AsOfTime`: snapshot timestamp (e.g. `2013-12-30T23:59:59Z`), the natural time-series key.
- `Term`: option expiry date; combined with `AsOfTime` gives time-to-maturity.
- `Forward`, `ImpliedSpot`, `DiscountFactor`: per-term forward, spot, and discount factor.
- `DataSourceId`, `IsEndOfDay`, `UnderlyingIndex` (always SPX), `VolSurfaceId`, `VolSurfaceTypeId`: metadata.

Note the filename contains a space — quote it in shell commands. The accompanying `:Zone.Identifier` file is a Windows download artifact and can be ignored.
